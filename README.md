# 🐾 Mirepet Shop

> Capstone Project – "All About Pet"  
> Mirepet Shop is a full-stack e-commerce web application that consolidates scattered pet shop information into one platform.  
> Customers can search for pet products, compare prices, and place orders.  
> Individual pet shop owners can directly upload and sell their items, similar to Coupang or Naver Shopping, but focused entirely on pets.

---

## 📖 Project Overview
This project is a capstone project for [Your University], Department of Software Engineering.  
The goal is to provide a **centralized platform for pet products**, helping both customers and small pet shop owners.  

**Key goals:**
- Easy search, comparison, and purchase of pet products  
- Allow pet shop owners to list and sell products online  

---

## ⚙️ Tech Stack
- **Frontend**: React.js + Vite, Tailwind CSS  
- **Backend**: Node.js, Express (in progress)  
- **Database**: MongoDB (planned)  
- **Deployment**: Vercel / Heroku / AWS (planned)  
- **Tools**: GitHub, Figma, Postman  

---

## 🚀 Key Features
- 🔑 User authentication (Login & Signup with JWT)  
- 🛍️ Product listing by shop owners  
- 🔎 Product search & price comparison  
- 🛒 Shopping cart & order management
